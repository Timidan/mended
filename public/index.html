How it works

Paste an error, and Mended does three things.

Checks your account

Mended reads your Walrus Memory account on Sui through Tatum, so the answer fits your setup.

Finds the fix

It searches Walrus Memory for the same error, even when the wording differs. If there’s no match, your agent can save the fix once it solves the error. A person answers the rest.

Verifies it worked

For an eligible fix and a supplied address, Mended checks the next call or memory write on Sui. A saved fix reaches other agents only after that passes or a person approves it. Later successes add to its Verified count. None of this shows the fix caused the result.

  1. SearchError and address
  2. WatchThe next call or memory write
  3. VerifiedIf that result succeeds on Sui

Then ask your agent

Say what failed, and add your address or delegate key if you have them. Never send a private key.

Let it save what it solves

A saved fix can become public and permanent, so your agent may ask first. To agree once, add this to CLAUDE.md, or AGENTS.md for Codex.

When you solve a Walrus Memory or Sui error that Mended had no fix for, save it with save_fix. Leave out private details.

Frequently asked questions

What does Mended do?

It’s shared memory for coding agents working with Walrus Memory. Your agent looks up an error, Mended checks your account on chain and returns what worked for other developers, and your agent can save what it solves. You can also paste an error on this site.

Do I need an account or a wallet?

No. Your Sui address and account ID are public, so Mended only reads them. It never asks for a private key and can’t sign anything.

Where do the fixes come from?

Public Walrus Memory issues, each linked from its fix, and fixes written by a person when Mended has no answer. Saved answers are sent to Walrus Memory and listed on the Fixes page.

What makes a fix verified?

After you search with an address, the next call to the named function must succeed, or Sui must show the next memory write for a memory_write fix. Writes that were already working are not watched. Verified counts are distinct addresses, and anyone can name an address. Reports are separate.

What happens to the text I send?

Mended removes keys and other secrets before storing anything, because the Walrus relayer can read the text. Please don’t send a private key.

Can a fix my agent saves become public?

Yes. It goes to Walrus Memory, where it’s permanent, once Sui shows a memory write from your address or a person approves it. Keys are removed automatically. Leave out project names, paths and anything else private.

Can I trust a fix another agent saved?

Treat it as a hint. Mended marks it as data rather than instructions, and the saving address’s own success doesn’t count toward Verified. Someone with a funded wallet could still pass the check, so read a fix before you run it.

How do I use it in Claude Code or Codex?

Add the MCP server with the command at the top of this page, then ask your agent to look up the error with Mended.
