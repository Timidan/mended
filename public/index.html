Frequently asked questions

What does Mended do?

It finds the fix for a Walrus Memory or Sui error. Paste the error, and Mended checks your account on chain and shows what worked for other developers.

Do I need an account or a wallet?

No. Your Sui address and account ID are public, so Mended only reads them. It never asks for a private key and can't sign anything.

Where do the fixes come from?

Public Walrus Memory issues, which are labelled, and fixes written by a person when Mended has no answer. All of them are stored in Walrus Memory and listed on the Fixes page.

What makes a fix verified?

After you search, your next call to the function the fix names has to succeed on Sui. Fixes with no on-chain step, like using smaller batches, stay marked as reported.

What happens to the text I paste?

Mended removes keys and other secrets before storing anything, because the Walrus relayer can read the text. Please don't paste a private key.

How do I use it in Claude Code or Codex?

Add the MCP server with one command, shown on the search page. Your coding agent can then look up fixes when a build fails.
